# Code of Conduct

This project follows a simple rule: **be respectful and assume good faith.**

- Treat everyone with kindness, whether they're filing a bug, asking a beginner question, or
  disagreeing with a design decision.
- Critique ideas, not people. Keep feedback specific and constructive.
- No harassment, discrimination, or personal attacks — in issues, pull requests, or anywhere else
  connected to the project.

Maintainers may edit, remove, or reject contributions and comments that violate this, and may block
repeat offenders. To report a concern, open a GitHub issue (or a private security advisory if it's
sensitive) — or contact the maintainer directly via their GitHub profile.

This is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org).
